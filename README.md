## 📘 Project Title
**Web-Based Kanban Task Manager with Drag-and-Drop Functionality**

---

## 🧩 Project Statement

Managing tasks efficiently is a major challenge, especially in collaborative or team-based environments where workflows must be **visually organized**. Traditional methods like simple lists or spreadsheets often lack **real-time interaction** and **intuitive visuals**.  

This project aims to develop a **fully frontend-based Kanban Task Manager** using **Angular**, featuring **drag-and-drop functionality** for smooth task management.  
It eliminates backend complexity by leveraging **LocalStorage** for persistent data, making it ideal for personal and small-scale use.

---

## 🎯 Project Outcomes

✅ A fully functional and user-friendly **Kanban Board**  
✅ Allows users to **create, edit, delete, and reorder tasks**  
✅ Tasks organized into columns — *To-Do, In Progress, Done*  
✅ **Drag-and-Drop** functionality powered by **Angular CDK Module**  
✅ Persistent task data stored in **LocalStorage**  
✅ **Responsive and clean UI** for seamless task management  
✅ Ideal for **personal productivity and small team management**

---

## 🧠 Modules to be Implemented

| Module | Description |
|--------|--------------|
| **Task Management Module** | Create, edit, delete, and assign tasks to specific columns. |
| **Drag & Drop and Column Management Module** | Enable smooth drag-and-drop movement across and within columns. |
| **LocalStorage & Notification Module** | Store and retrieve task data from browser LocalStorage and show alerts/snackbars. |
| **Testing, Review, and Documentation** | Final review, bug fixing, and preparation of user and technical documentation. |

---

## 🗓️ Week-wise Implementation Plan

### **Weeks 1–2: User and Task Management Module**
- Implement core task CRUD (Create, Read, Update, Delete) operations.  
- Assign tasks to columns: **To-Do, In Progress, Done**.  
- Store essential task details such as title, description, and priority.

### **Weeks 3–4: Drag & Drop and Column Management Module**
- Integrate **CdkDragDrop** for moving tasks between columns.  
- Allow **reordering** tasks within the same column.  
- Define default columns and optionally allow users to add/remove columns dynamically.

### **Weeks 5–6: LocalStorage & Notification Module**
- Store board structure and task data in **LocalStorage**.  
- Automatically reload tasks on page refresh.  
- Show **snackbars/alerts** when tasks are created, updated, or deleted.

### **Weeks 7–8: Testing, Review, and Documentation**
- Perform complete testing for UI, functionality, and performance.  
- Fix identified bugs or usability issues.  
- Prepare final **documentation and presentation**, including:
  - System Architecture  
  - User Guide  
  - Technical Specifications
